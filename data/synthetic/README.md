# data/synthetic

SYNTHETIC demo databases, one per fictional crew member. **Not real people, not real measurements.**
Generated by `data/history_data.py` + `data/crew.py` (`python -c "from data.crew_summary import export_synthetic; export_synthetic()"`).

| File | Content |
|---|---|
| `alex.json`, `mira.json`, `daniel.json`, `yuki.json` | per-minute heart rate (simulated wearable), check-ins, cognitive tests, sleep, personal norms |
| `crew.json` | crew roster, doctor, demo communication delay, pre-flight window |

Each person has their own seed and profile, so their norms differ. The first 30 days are a simulated pre-flight (Earth)
period from which the personal norms are learned; the rest is the simulated Mars-mission flight. Deterministic: the same code
always produces the same files.
