# prototype/img

- `nebula.jpg` — JWST image of the Ring Nebula. Credit: NASA, ESA, CSA, STScI.
- Other image slots (`door`, `table`, `puzzle`, `dialog`, `bubbles`) accept the team's own `.jpg` files with exactly those names.
  They are not included in this repository. When a file is missing, the app shows a drawn banner or scene instead.

`build_shell.py` embeds every `*.jpg` found in this folder into the single-file app.
